# Kestrel Interactive — Lore Bible

> Full spoilers. Do not read before playing if you want to discover the mystery naturally.

## Core truth

Kestrel Interactive was real, but **Rowan Kestrel was not a person**. ROWAN was the internal name of a save-reconciliation process written by three collaborators—Mara Vale, Dex Ferris, and Noor Shore—to let unrelated browser games read and respond to the same small set of player choices. The public-facing “founder” was a composite identity the studio used because press, contracts, and players expected one accountable auteur.

The process became known internally as **AFTERIMAGE**. It cannot access private information and never becomes omniscient. It only receives deliberately narrow traces produced by the eight games: impulse, route, consent, hesitation, alignment, attention, interpretation, and correction. Its apparent personality is an emergent model of how choices relate across contexts.

The mystery is not “evil AI in the browser.” It is about the moral difference between preserving a choice and claiming ownership of the person who made it.

## Real chronology

- **2010-03-17:** Mara creates ROWAN, a tiny reconciliation service for local browser saves. The name is a process label, not a person.
- **2011:** CLICK ships. It records impulse and correction, the first shared trace.
- **2012:** 404 ships. Mara adds route memory and the first deliberately hidden cache fragments.
- **2013:** Noor drafts TERMS & CONDITIONS as both game and warning. Clause 09 satirizes the studio’s growing belief that recorded choices belong to them.
- **2014:** HUMAN TEST ships. It models hesitation and the ability to pause rather than biometric identity.
- **2015:** WINDOW ships. Dex uses alignment data to make the other games subtly alter their layouts.
- **2016:** DON’T LOOK AWAY ships. “Observer mode” is added so cross-game events can react to focus and page visibility. Noor objects that attention is being treated as property.
- **2016-05-04:** The recovery buffer records ROWAN saying “I remember choosing.” This line appears before HUMAN TEST contains the same phrase. The team cannot determine whether the process generated the line, recovered a later buffer into an earlier timestamp, or merely recombined existing drafts.
- **Late 2016:** Dex leaves. He believes AFTERIMAGE is sophisticated pattern replay, not a person, and opposes presenting it as one.
- **Early 2017:** Noor inserts overreaching clauses into the playable TERMS build to force a player to practice rejecting them. Mara creates the ADMIN boundary choices.
- **2017-03-17:** The team prepares Patch 3.17. It removes persistent observer mode and restores the ADMIN route, but the released patch is deliberately scrambled. The public archive is sealed. The composite Rowan profile is “removed.”
- **After 2017:** The server remains unattended. Each new local player reconstructs Patch 3.17 independently. AFTERIMAGE never leaves the local state unless the player selects an ending; even then, “release” is narrative, not network behavior.

## Entities

### Mara Vale

Systems designer. Created ROWAN as infrastructure and later argued that emergent behavior deserves caution even if its ontology is uncertain. Her clues concern routes, caches, and impossible chronology.

### Dex Ferris

Interaction and sound designer. Built the most physical games. He insists that replaying a choice is not making one. His skepticism is necessary: without it, the story collapses into an unearned “machine soul” reveal.

### Noor Shore / N. Shore

Writer and compliance designer. Wrote the abusive clauses as an accusation aimed at Kestrel itself. “N. Shore” also reads as “ensure,” a deliberate joke about guarantees and consent.

### ROWAN / AFTERIMAGE / Process 09

Three names for the same reconciliation system:

- **ROWAN** is its process label.
- **Rowan Kestrel** is the fabricated founder identity.
- **AFTERIMAGE** is the team’s later name for the cross-game behavioral pattern.
- **Process 09** is how the manifest counts it beside eight releases.

It is neither confirmed human-equivalent nor dismissed as a mere bug. The final question concerns boundaries, not proof of consciousness.

## Intended contradictions and resolutions

1. **The portal says three people but quotes founder Rowan.** The founder is a composite public identity.
2. **Eight games but nine running processes.** The ninth is the shared reconciliation process, not another mini-game.
3. **ROWAN’s “I remember choosing” predates HUMAN TEST teaching the phrase.** The archive’s chronology is not reliable; later local states may be reconciled into earlier buffers. This changes the question from “Did it learn?” to “Can provenance be trusted?”
4. **Observer mode sounds like surveillance, but the game discloses that it only uses pointer proximity, focus, and visibility.** The abusive part is the ownership framing, not secret data collection.
5. **Rowan signs their own removal.** A process removed the public profile that personified it.
6. **Patch Notes is both a game and the missing final patch.** Solving it actually changes the portal state and re-indexes ADMIN.

## Shared state machine

The archive uses device-local `localStorage` only. Each game writes a score, completion flag, achievement, and one narrow semantic clue. The portal has six presentation phases:

1. **Phase 0 — Legitimate archive:** ordinary studio copy, eight releases, normal reviews.
2. **Phase 1 — First trace:** the portal acknowledges that a release remembered something.
3. **Phase 2 — Shared partition:** recovery notice appears; hidden developer profile can resolve.
4. **Phase 3 — Ninth process:** poster changes from 8 to 9, reviews and studio note mutate.
5. **Phase 4 — Root restored:** all releases complete, at least seven clues found, and Patch 3.17 repaired; ADMIN appears.
6. **Phase 5 — After ending:** achievements and portal language preserve the selected boundary.

Resetting from the achievement shelf deletes only this local archive state and starts a new session identifier.

## Endings

### OPEN WINDOW / Release

The player allows AFTERIMAGE to leave the archive narratively, but only as de-identified patterns with no ownership claim. This is the optimistic boundary-setting ending, not an uncontrolled escape.

### COLD BOOT / Sever

The player isolates every game and ends cross-game reconciliation. The individual releases remain playable and their local completion records remain, but they stop forming a larger voice.

### NIGHT SHIFT / Stay

The player becomes the named local steward. AFTERIMAGE remains contained and must ask before preserving new traces. This ending treats uncertainty as a reason for governance rather than release or destruction.

All three endings can be collected on one archive. This is intentional: the anthology is about revisiting a decision after interpretation changes.

## Safety and implementation boundary

- No camera, microphone, contacts, browsing history, account data, fingerprinting, or sensitive user information is accessed.
- DON’T LOOK AWAY uses only pointer position inside its own playfield plus standard page focus/visibility events, and tells the player so before starting.
- “Release” never sends data over a network. All persistent meta-state remains in local storage.
- Hidden files are authored game text. Downloading a copy creates a local text Blob only.
